# 内容维护说明

本文件说明“退税小笔记”内容库的数据流、目录用途和维护边界；具体 Skill 路由由项目根目录 `AGENTS.md` 负责。

## 内容资产流转

原始线索 → 灵感库 → 成熟候选与选题池 → 用户确认 → 正式文案 → 实际发布 → 明确归档 → 历史内容 → 复盘与延展灵感

- `03-选题规划/灵感库/` 保存竞品观察、客户咨询、服务交付、发布反馈、历史延展和覆盖缺口等原始线索。
- [[待发布选题]] 与各业务选题池保存成熟候选，不代表内容已经发布。
- `01-历史内容/` 仅保存实际发布且用户明确要求归档的内容，是已发布事实来源。
- 三个 JSONL Index 是默认机器检索入口，可从 Markdown 重建。
- `02-内容地图/` 与 `04-内容复盘/` 是按需或周期性维护的派生资产，不替代历史事实。

## 账号隔离

- 本库只保存 `tsxbj` 的内容资产。
- 不复制或引用其他账号的历史、灵感、候选、复盘和素材记录。
- 可借鉴公共方法，但不得把其他账号数据合并进本库。
- 写入前检查目标路径仍位于 `accounts/tsxbj/`。

## 维护约定

- 一条灵感一篇笔记，一条已发布视频一篇历史笔记。
- 历史内容按发布日期保存至 `01-历史内容/YYYY/YYYY-MM/`。
- 分类固定值以 [[固定选项库]] 为准。
- 灵感和候选状态引用 `shared/schemas/content-state-machine.md`。
- 政策、税率、期限、处罚和办理流程必须核验当前有效的官方来源。
- 只有“确认实际发布”和“明确要求归档”同时成立时，才执行历史归档。
