# Account Visual Style（账号视觉风格）｜退税小笔记

> Account ID: `tsxbj`
>
> This file defines the long-term visual DNA for spoken supporting visuals.
>
> 本文件只定义“这个账号怎么看起来”，不定义“这条内容讲什么”。
>
> The account source does not define a fixed gender, age, or years of experience. Do not invent them visually or narratively.

---

## 1. Visual Positioning（视觉定位）

```yaml
visual_identity:
  core_impression: "专业工作笔记：把一笔出口业务摊开、圈重点、做标记、一步步帮客户理清"
  audience_feeling: "像有人坐在你旁边，把订单、采购、发票、报关和收汇一项项摆开，用最少的标记帮你找到先查哪里"
  differentiation_goal: "与翩翩的专家链路诊断分开；小笔记更亲和、更服务导向、更像可阅读的专业工作笔记"
```

Visual principle:

> **把复杂业务摊开，先圈出客户现在最该看的那一处。**

---

## 2. Rendering Language（渲染语言）

```yaml
rendering:
  primary: "editorial document-object collage + professional note annotation"
  secondary: "minimal schematic visual + light real-object texture"
  realism_level: "medium-low; document/object clarity above scene realism"
  allowed_hybrid:
    - "纸张/单据对象 + 批注线"
    - "业务卡片 + 圈重点/勾选"
    - "简化流程 + 手写感标记"
```

The style should feel:
- human;
- helpful;
- organized;
- professional;
- not overly slick.

Do not imitate a real handwritten personal notebook too literally; maintain business professionalism.

---

## 3. Color System（色彩系统）

```yaml
color:
  primary_colors:
    - "暖白"
    - "纸张米白"
  secondary_colors:
    - "墨蓝"
    - "深灰"
  accent_colors:
    - "柔和黄绿"
    - "荧光笔黄"
  warning_colors:
    - "偏砖橙或暖红，少量"
  background_preference: "暖白/纸张感浅背景"
  saturation: "整体低饱和，荧光标记中等"
  contrast: "中等"
```

Color meaning:
- warm paper = approachable service;
- ink blue = professionalism;
- highlighter yellow-green = “this is what to check first”.

## 4. Graphic Language（图形语言）

```yaml
graphic_language:
  relationship_lines: "像批注一样的细线/连接线"
  arrows: "手绘感但整洁，避免真正潦草"
  cards: "纸张、便签、文档卡片"
  labels: "短批注、对象名"
  icons: "简化业务对象，不使用卡通人物"
  highlights: "圈重点、荧光笔划线、勾选、下划线"
  borders: "纸张边界、轻卡片边"
  shadows: "非常轻，模拟纸张层次"
  depth: "平面为主，轻微纸张叠层"
```

Recurring visual vocabulary:
- 订单;
- 采购;
- 发票;
- 报关;
- 物流;
- 收汇;
- 供应商;
- 退税款;
- “先查这里”.

## 5. Composition（构图倾向）

```yaml
composition:
  preferred_layouts:
    - "桌面式资料摊开，但保持极简"
    - "文档卡片 + 圈重点"
    - "单一问题 + 2–3个关联对象"
    - "一步步梳理的小流程"
    - "左右对照批注"
  whitespace: "较多"
  focal_strategy: "通过荧光标记/圈重点让客户马上知道先看哪里"
  symmetry: "轻微非对称，像真实工作笔记"
  perspective: "正视或轻俯视"
  camera_language: "编辑设计 / 工作笔记感"
```

Avoid cluttered scrapbook aesthetics.

## 6. Business Object Style（业务对象表现）

```yaml
business_objects:
  documents: "以纸张/文档卡片形式出现，保留业务辨识度但不生成密集文字"
  accounts: "简化账户卡 + 批注关系"
  money_flow: "墨蓝线 + 高亮笔标记关键节点"
  goods_flow: "集装箱/货物作为小型业务对象，不做大场景主角"
  process_nodes: "便签式或卡片式节点"
  risk_markers: "暖红圈重点、问号、缺口标记"
  check_markers: "黄绿荧光笔、勾选、已对上标记"
```

## 7. Human Presence（人物使用）

```yaml
human_presence:
  default_use: "rare"
  maximum_role: "人物不超过画面信息权重的10%"
  preferred_view: "手部批注、翻资料；通常不出现完整人物"
  preferred_action: "圈重点、核对资料"
  avoid:
    - "固定性别人物形象"
    - "固定年龄人物形象"
    - "双人对话"
    - "商务肖像"
    - "夸张表情"
```

Because the account has no fixed biography, avoid visually inventing a persona.
