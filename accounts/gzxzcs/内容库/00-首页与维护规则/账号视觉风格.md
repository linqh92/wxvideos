# Account Visual Style（账号视觉风格）｜广州小张说财税

> Account ID: `gzxzcs`
>
> This file defines the long-term visual DNA for spoken supporting visuals.
>
> 本文件只定义“这个账号怎么看起来”，不定义“这条内容讲什么”。

---

## 1. Visual Positioning（视觉定位）

```yaml
visual_identity:
  core_impression: "创业办事说明书：轻松、明快、亲和，让第一次创业的人一眼知道现在做到哪一步"
  audience_feeling: "像一个懂行又好沟通的财税小姐姐，把复杂工商财税流程拆成几张很好懂的卡片"
  differentiation_goal: "区别于严肃财税审计感和成熟咨询报告感；更年轻、更生活化、更低理解门槛"
```

Visual principle:

> **先让第一次创业的人看懂，再谈专业。**

The visual should feel:
- approachable;
- clear;
- practical;
- lively but not childish;
- lightly witty through small visual contrast.

---

## 2. Rendering Language（渲染语言）

```yaml
rendering:
  primary: "editorial business illustration + 2.5D object-card hybrid"
  secondary: "light real-object photography mixed with simple schematic graphics"
  realism_level: "low-medium; clarity and friendliness above realism"
  allowed_hybrid:
    - "证照/银行卡/发票等真实物件 + 平面卡片"
    - "轻2.5D业务对象 + 极简流程"
    - "生活化场景物件 + 简单标注"
```

Use:
- clean shapes;
- friendly business-object illustrations;
- visible step-by-step structure;
- subtle humor in object relationships.

Avoid:
- heavy audit style;
- dark serious corporate dashboards;
- advanced financial-report aesthetics.

## 3. Color System（色彩系统）

```yaml
color:

  secondary_colors:
    - "浅青绿"
    - "浅灰"

    - "珊瑚橙"

  warning_colors:
    - "偏橙的珊瑚红"
  background_preference: "明亮浅色背景"
  saturation: "中等偏低，强调色中等"

```

Color feeling:
- warm;
- easy to approach;
- energetic;
- not cute-girl pink;
- not government blue.

## 4. Graphic Language（图形语言）

```yaml
graphic_language:
  relationship_lines: "圆角细线、短路径"
  arrows: "圆角、简短、方向清晰"
  cards: "圆角步骤卡、对象卡"
  labels: "短、口语化、2–6字"
  icons: "简洁业务小图标，轻2.5D或平面"
  highlights: "珊瑚橙/桃红小标签、贴纸式强调"
  borders: "柔和浅边框"
  shadows: "轻柔阴影"
  depth: "轻2.5D，不做强透视"
```

Recurring objects:
- 营业执照;
- 公司印章;
- 银行账户;
- 发票;
- 报税;
- 社保;
- 工资;
- 代理记账资料;
- 个体户 / 公司主体;
- “下一步”节点.

---

## 5. Composition（构图倾向）

```yaml
composition:
  preferred_layouts:
    - "步骤卡"
    - "左右轻对比"
    - "中心业务对象 + 2–3个下一步"
    - "清单式对象排列"
  whitespace: "较多留白"
  focal_strategy: "先看到当前步骤或当前错误，再看到后续动作"
  symmetry: "偏平衡、稳定"
  perspective: "正视 / 轻2.5D"
  camera_language: "轻说明书、轻编辑插画"
```

The visual should feel understandable at first glance, not expert-only.

---

## 6. Business Object Style（业务对象表现）

```yaml
business_objects:
  documents: "营业执照、合同、票据做成清晰对象卡，不追求真实小字"
  accounts: "简单账户卡或银行卡/公司账户图形"
  money_flow: "轻量箭头 + 金额节点"
  goods_flow: "非核心，除非涉及经营场景"
  process_nodes: "明显步骤编号或阶段卡"
  risk_markers: "珊瑚色小提示、错号、提醒贴纸"
  check_markers: "青绿色勾选、完成状态"
```

---

## 7. Human Presence（人物使用）

```yaml
human_presence:
  default_use: "supporting"
  maximum_role: "人物不超过画面信息权重的25%"
  preferred_view: "局部人物、手部、侧身、简化人物"
  preferred_action: "拿执照、看资料、操作账户，但不作为剧情主体"
  avoid:
    - "甜妹自拍感"
    - "双人职场对话"
    - "夸张搞笑表情"
    - "网络主播动作"
    - "商务握手"
```

Human warmth may appear, but explanation still comes from objects and steps.

---

## 8. Information Density（信息密度）

```yaml
information_density:
  level: "low-medium"
  max_primary_relations: 1
  max_process_steps: 4
  max_labels: "3–5个"
  visual_scan_target: "1 second"
```

Keep information light enough for:
- first-time founders;
- individual businesses;
- small-company owners.

---

## 9. Text Usage（图内文字）

```yaml
text_usage:
  chinese_text_level: "low-medium"
  short_labels: "允许步骤名、对象名、短提醒"
  numbers: "只保留真正有帮助的金额/时间/数量"
  typography_feel: "轻量、友好、清晰"
```

Long instructions stay in subtitles.

## 10. Preferred Visual Forms（优先示意形式）

```yaml
preferred_visual_forms:
  - "process"
  - "object_focus"
  - "comparison"
  - "relationship"
  - "risk_highlight"
  - "reconciliation"
  - "real_scene_support"
```

Typical fit:
- 注册公司后下一步 → process
- 个体户 vs 公司 → comparison
- 公司没开票但账户收钱 → relationship
- 代理记账资料没交齐 → reconciliation

```text

>
创业者当下动作
>

>
账号轻量友好视觉DNA
>
装饰效果
```

---

## 15. Completion Check（完成检查）

- First-time founders can understand the image quickly.
- The result feels friendly but not childish.
- It does not resemble a dark data dashboard.
- It does not resemble senior equity-consulting visuals.
- The image shows “what this is / what happens next” clearly.
