# 中文口播表达

## 适用范围

本文件用于 `CONTENT_FORMAT=spoken` 的说话生成与编辑。获客目标、事实边界、账号身份和编导流程由口播 Skill 与公共规则定义。

This reference applies ONLY to `spoken-copywriting` and MUST NOT be inherited by `text-broadcast-copywriting`.

## 说话情境

依据当前角色与客户关系生成自然简体中文。先知道这位客户为什么关心、出镜者想说明什么，再选择本题的句子。直接写成说话，听众应在不看字幕的情况下理解。

说话单元可以是一句判断、一段解释、半句补充、自然提问或条件说明。长短和语法形态随意思变化；语气词、省略、轻微自我修正按人物与情境使用。句长、问句、幽默和语气词均无配额。

对象清楚比句子短更重要。专业名词需要时准确使用，并说明对客户有什么影响。代词不明确时重复对象；重复承载强调、情绪或听觉澄清功能时可以保留。

前后关系听得懂时直接承接，需要解释转折或因果时使用自然连接。收尾停在本题的有用判断、结果或真实服务需求上。

## 角色资料的使用

账号行为模型描述判断倾向，例句描述态度和节奏，业务词列举描述适用范围。它们均不提供可直接填入正文的段落、词组或步骤。

本题只调用有用的角色特征。角色的专业知识可以参与内部判断；正文中每个业务对象、条件和操作建议都应能解释为什么与这个问题有关。

## 跨稿件表达检查

优先比对当前对话中同一账号最近的至多三篇已完成口播。样本不足时，可读取当前账号 `01-历史内容/_history-index.jsonl`，按发布时间选择明确标记 `content_format=spoken` 的近期记录，合计最多读取三篇正文。

索引路径相对仓库根目录解析，读取前确认仍位于 `accounts/{CURRENT_ACCOUNT}/内容库/`。历史 Markdown 是正文事实源。无索引、无口播记录或无可用正文时跳过历史比对，检查当前草稿与角色资料的表达依赖；不得声称完成了跨稿件验证。旧记录缺少载体字段时不猜测。

比对关注：

- 开场、转折、收尾是否重复相同句法和信息释放顺序；
- 关键词组合是否跨无关选题惯性出现；
- 是否将同一组专业对象或检查步骤搬入新问题；
- 是否沿用例句，仅替换名词、数字或同义词。

判断重复是否必要：同一专业名词、连续专题的明确对象和有听觉作用的重复可以保留；缺少本题理由的重复，从当前客户疑问与事实关系重新组织。变化来自问题差异，避免为了区别而硬换开场、强加幽默或改变事实结论。

## 编辑标准

朗读检查重点是客户能否听懂、愿意听、相信这个人的判断。书面抽象表达改为能理解的对象与动作，歧义补清，冗余删去。

判断句子的价值时同时考虑信息、停留、情绪、人物关系、信任与咨询意愿。有作用的人物观察和自然承接可以保留。发现问题后针对性修改，保留已成立的表达。
