# 内容状态机

本文件是灵感、候选选题与发布状态的唯一公共定义来源。其他 Agent、Skill、模板和维护文档只引用本文件，不另建状态枚举。

## 灵感状态

```text
待分析 → 可入池 → 已转选题
   └──→ 已放弃
可入池 ─────→ 已放弃
```

| 状态 | 含义 | 允许的下一状态 |
| --- | --- | --- |
| `待分析` | 原始灵感已保存，尚未完成场景补充、历史查重、必要事实核验和可用性判断 | `可入池`、`已放弃` |
| `可入池` | 已完成必要分析，可作为未来选题来源 | `已转选题`、`已放弃` |
| `已转选题` | 已形成正式候选选题 | 终态 |
| `已放弃` | 不再继续使用 | 终态 |

普通选题请求不得批量改变灵感状态。只有用户明确要求“写回、入池、更新状态”时，才持久化状态变化。

## 候选选题状态

```text
待核验 → 可推荐 → 已采用 → 已发布
   └──────────────→ 已放弃
可推荐 ──────────→ 已放弃
已采用 ──────────→ 已放弃
```

| 状态 | 含义 | 允许的下一状态 |
| --- | --- | --- |
| `待核验` | 方向成立，但政策、事实、数据或办理条件仍需核验 | `可推荐`、`已放弃` |
| `可推荐` | 已满足推荐要求 | `已采用`、`已放弃` |
| `已采用` | 用户已明确选择该题，但内容尚未实际发布归档 | `已发布`、`已放弃` |
| `已发布` | 内容已实际发布，且 `publish-archive` 已完成归档 | 终态 |
| `已放弃` | 不再继续使用 | 终态 |

`已采用 ≠ 已发布`。只有 `publish-archive` 可以把候选改为 `已发布`。

## 发布与归档条件

以下两项必须同时成立才允许归档：

1. 用户明确确认内容已经实际发布或更新完成；
2. 用户明确要求归档、写入知识库或更新历史库。

文案完成、用户采用、排期完成或单独一句“已发布”均不自动触发写库。

## 数据优先级

```text
正式历史 Markdown = 已发布事实源
三类 JSONL Index  = 可删除重建的机器检索层
内容地图与复盘     = 派生辅助数据
```

Index 与 Markdown 冲突时，以 Markdown 为准并重建 Index。
