# 选题记忆分层读取

## 默认入口

账号锁定后读取定位、`推荐记录/_preferences.json` 的有效偏好及最近 5 个推荐批次与关联反馈。通过 `shared/scripts/topic-memory.py --account <id> --mode recent` 获取近期数据；不直接把所有月度日志交给模型。局部换题须结合返回的被替换题来源核对原批次，保留未替换项，不把局部批次当整轮选择范围。

`推荐记录/YYYY-MM.jsonl` 是永久原始事实源；不为降低上下文删除或搬移。`_retrieval.sqlite` 是可重建的本地检索缓存，不作为内容状态或事实源；不整文件加载到模型。脚本仅使用 Python 标准库，可用本机 Python 或已配置的运行时。

## 旧题按需查重

主编形成初步方向后，运行 `--mode search --terms <客户词> <决策问题关键词> <同义词> --limit 10`；用 `--offset` 翻页。检索涵盖全部旧推荐，返回问题、答案摘要、最近推荐时间和原记录定位。按来源只读取命中的 JSONL 行，核对关键条件、相关反馈和回归理由。

关键词检索不等于语义去重；零命中不能证明无重复。围绕客户、业务动作、痛点和同义表达分别检索，主编比较问题与答案。有重复风险或结果被截断时继续检索/翻页，不为控制长度直接放行。明确否定始终按其有效范围执行，不能因记录超过近期窗口而失效。

## 长期偏好摘要

`推荐记录/_preferences.json` 是可从原始反馈恢复的派生资产，由主编增量维护。结构：`account_id`、`updated_at`、`processed_feedback_count`、`last_feedback_event_id`、`entries`。每项保留 `scope`（题目/批次/方向）、`scope_description`、`signal`、`user_text`、`source_event_ids`、`source_refs`、`effective` 及 `superseded_by`。引用来源时保留文件和行号。不能创造新的内容状态。

首次创建或恢复时，调用 `--mode feedback --offset 0 --limit 20` 分页处理明确偏好、否定与恢复反馈；`selected` 保留在原始日志和检索缓存中，不建立长期偏好条目。普通选题从 `processed_feedback_count` 继续，只处理新增反馈。每页完成后才推进计数和末事件 ID；先确保原日志及缓存同步成功。摘要缺失/落后时先补处理，不能把未处理的长期约束视为不存在。处理中断后可从上次计数继续，按事件 ID 防重复。写摘要采用临时文件后原子替换，失败保持旧摘要并明确未更新。

摘要保存仍有效的明确偏好、否定及恢复范围，不照搬所有推荐。选择某题不推断长期偏好或获客效果；沉默、多次跳过不升级为永久禁用。“本次”范围不得推广到以后；新反馈只替代同一范围内冲突的条目，不能全局解除旧限制。跨月补录按实际事件时间解释，发生时间不清时保留冲突并核对原话。

过期批次约束由旧题检索追溯，不挤入长期方向偏好。明确题目否定数量较多时，摘要保留方向级有效项和题目级来源目录，针对初步方向检索具体否定；不能静默截掉有效限制。完整摘要可在磁盘保留，模型只接收本轮相关项；通用有效限制始终读取。

## 增量与失效

工具自动同步新增事件：记录月度文件大小、修改时间与摘要；未变文件不重读，变动文件核对旧前缀，只解析追加部分。首次构建可扫描全部日志，但不会把全量日志返回模型。缓存同步失败则停止使用缓存，不能以旧缓存证明没有限制。

原日志被改写、截断或删除时工具报告需要重建：在当前账号内保留旧缓存备份后重建缓存，并从原反馈重新生成摘要。正常追加不得全量重建。恢复前核对日志；缓存可以重建，原日志不能从缓存还原。用户直接编辑摘要不替代原始反馈，长期改变应记录明确反馈事件。

## 其他索引与读取预算

History/Candidate/Idea 三个索引继续作为检索入口。体积较小时可读紧凑元数据；增长后先在本地按业务、客户、场景和问题筛选，仅返回相关元数据，按需扩展同义词与相邻方向。无指定方向时先返回业务分布摘要和每个相关方向少量样本，防止只看到熟悉业务。全量扫描可以在本地工具内完成，不等于全量输出到上下文。

默认近期 5 批，旧推荐每次 10 个命中、反馈每页 20 条；这是初始读取量，不是查重证据硬上限。返回是否还有结果。记录增长时常规默认读取范围应保持稳定，必要追溯单独按需增加。不得仅按时间遗忘旧否定，也不得声称总耗时恒定：本地检索仍随数据量增长。

验证重点：旧题超出近期仍可命中；局部换题不误伤保留项；明确否定/恢复不丢失范围；摘要落后会补读；未变日志不重复解析；缺失或冲突不会静默放行。
